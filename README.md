# LeetCode Solutions

A collection of solutions submitted to LeetCode. Each problem lives in its own
directory so that its solution and explanation stay together.

## Organization

Use the problem number and a short title in the directory name:

```text
problems/
└── 0001-two-sum/
    ├── solution.<extension>
    └── README.md
```

Keep the solution in the language used for the submission. The problem README
should summarize the approach and analyze its complexity:

```markdown
# <Problem number>: <Problem title>

- **LeetCode:** <problem URL>
- **Language:** <language>

## Approach

<Brief explanation of the algorithm.>

## Complexity

- **Time:** O(...)
- **Space:** O(...)

## Notes

<Important details, edge cases, or implementation notes.>
```
